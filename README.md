# Insiya Saif — Portfolio draft

A responsive static portfolio inspired by the selected dark, dashboard-style reference. It uses HTML, CSS, and a small JavaScript file so it can be published directly with GitHub Pages.

## Preview

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a public GitHub repository named `insiya-portfolio` (or `YOUR-USERNAME.github.io` for the root profile URL).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub Pages will provide the published URL after deployment.
